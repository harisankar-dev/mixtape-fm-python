# mixtape.fm

A little music, sent with feeling.

Create a digital mixtape with a personal note, a custom player style, and YouTube tracks. Share it with a link.

## Features

- Personalised title, sender, recipient, note, and cover image
- Up to 20 YouTube tracks
- Four player styles: CD, iPod, scrapbook, and webcore
- Shareable links with mixtape details encoded in the URL
- No database or Supabase required

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
